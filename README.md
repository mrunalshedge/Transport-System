# 🚗 Transportation Booking Website - CDAC Project

This is a responsive web-based transportation booking system developed using **HTML**, **CSS**, and **JavaScript** as part of the WPT module. The project includes splash screen animation, interactive navigation, vehicle selection, and dynamic fare confirmation.


## 📁 Folder Structure



## ✅ Features Implemented

### 1. 🔥 Splash Screen
- Full-screen splash logo animation on site load
- Disappears after 2.5 seconds
- Clean zoom-in effect using CSS animation

### 2. 📍 Navigation Bar
- Sticky, responsive navbar with logo + nav links
- Each link scrolls to its section
- Buttons styled with hover and box-shadow effects

### 3. 🎯 Hero Section
- Left: Tagline, bold heading, subheading
- Right: Full-width transport image (`crossborder.jpg`)
- Hero text is placed inside a soft-glass effect box

### 4. 🛣 Marquee Banner
- Horizontal scrolling text for announcements
- Positioned right under navbar

### 5. 🚚 Book a Ride Section
- Vehicle types shown as **separate cards**
- Each card includes icon + label
- Click to select → highlights selected vehicle

### 6. 🧠 JavaScript Logic
- Stores selected vehicle and price in localStorage
- On "Next", opens `confirm.html` with selected vehicle data

### 7. 💰 Fare Confirmation Page (`confirm.html`)
- Shows selected vehicle type and estimated fare
- Retrieves info from localStorage and displays


## 🛠 How to Run

1. **Download the project folder** or clone via Git.
2. Open `form.html` in a browser.
3. Navigate to the "Book a Ride" section.
4. Select a vehicle → Click **Next**
5. `confirm.html` will show your selection and price.

 ## 🚀 Technologies Used

- HTML5
- CSS3 (Flexbox, Transitions, Keyframes)
- JavaScript (DOM Manipulation, LocalStorage)
